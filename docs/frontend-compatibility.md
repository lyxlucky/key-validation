# 保留标签与弹窗兼容性

工作区使用 React Activity 保留已打开页面。卡密操作表单由所属标签持有；关闭标签会释放尚未提交的草稿。已提交但结果不确定的请求由工作区单独保管，可在其他标签或刷新后查询原回执，避免重复续期。

当前 `@rc-component/dialog@1.10.0` 在 Activity 重新连接布局效果时，会把尚未恢复的子组件引用展开为一个不完整的对象。实际浏览器复现为 `contentRef.current?.focus is not a function`，可能导致整个工作区退出渲染。`frontend/scripts/patch-dialog.mjs` 将 `focus` 和动画状态查询改为调用时转发到当前子组件引用，保留正常焦点管理和过渡动画。

`npm ci` 的 `postinstall` 自动应用此兼容修正，覆盖 ESM 和 CommonJS；脚本可重复执行，并严格检查版本和源代码模式。Docker 前端构建同样先复制脚本再安装依赖。依赖版本由 npm override 固定，升级时需检查上游实现，移除或更新脚本后运行 `workspace-tabs.spec.ts`、`motion.spec.ts` 和弹窗相关流程。不要跳过安装脚本，否则该兼容修正不会生效。

回归场景覆盖：打开卡密详情及续期弹窗，填写草稿，后退切页再返回，检查草稿、焦点及无运行时异常；关闭标签重新打开，检查草稿释放；丢失续期响应后关闭原标签，在其他页面查询回执，确认只延长一次。
