# KeyGate 后续功能 Spec

创建日期：2026-10-05。更新：2026-10-09。状态：除 F18 外的 21 项功能均已实现、验证并通过独立审查；剩余 13 项及管理体验的最终验收已完成。F18 支付自动发卡按用户要求暂缓。Windows 手动测试 demo 按已确认的顺序在该验收之后制作。

初始六项管理扩展见 `2026-10-05-management-expansion-design.md`。本表保留后续 22 项的完整清单，已完成规则见 [账号安全与换绑规格](2026-10-05-account-security-rebinding-design.md) 和 [授权策略规格](2026-10-06-authorization-policies-design.md)，最新验证见 [验证记录](../../verification.md)。

| 编号 | 功能 | 预期行为与验收 | 已确定的规则 |
| --- | --- | --- | --- |
| F01 | 自行修改密码（已完成） | 旧密码验证、自行改密、其他会话失效、首次改密服务端门禁 | 新建 API 账号、CLI 非管理员和管理员/CLI 重置密码要求改密；现有账号与 CLI 引导管理员保持兼容 |
| F02 | 冻结/解冻授权（已完成） | 冻结撤销现有会话、禁止激活；解冻恢复剩余可用时间；保留冻结历史 | 仅已激活未到期可冻结，冻结期间不可续期；禁用优先，解冻不解除禁用、不恢复旧会话 |
| F03 | 高级搜索????? | 新增激活/到期日期区间、设备标识和组合条件，分页保持筛选 | 条件按 AND 组合、时间区间左闭右开；设备在指定可见应用内按现有摘要精确查找，不进入 URL 或本地存储；本版不保存筛选 |
| F04 | 设备换绑规则（已完成） | 单卡次数/窗口/冷却配置、客户端释放自身设备、人工重置与独立历史 | 新卡每卡滚动 30 天最多 3 次、冷却 24 小时；旧卡不限制；修改规则不清次数，人工重置留审计 |
| F05 | 并发会话控制（已完成） | 设备绑定上限和同时在线上限独立；竞争激活不突破配额 | 超限拒绝，同设备替换旧会话；卡种配置后发卡保存快照，旧卡上限等于原设备上限 |
| F06 | 激活期限（已完成） | 未激活卡超过发行有效期不能激活；激活后的使用时长独立 | 卡种可设 1–3650 天，默认不限；到期等值拒绝，续期不重置激活期限，超期需重新发行 |
| F07 | 试用授权（已完成） | 设备可领限时试用，重复领取受到限制；试用升级正式授权 | 每应用每设备一次；默认关闭/1 小时，重试不延期，同设备正式激活原子升级；设备标识不等于硬件证明 |
| F08 | 授权功能分级（已完成） | 卡种绑定功能集，客户端读取并验证已授权能力；签发后规则可追踪 | 发卡保存功能快照，改卡种不追改旧卡；试用升级采用正式卡快照，客户端同时检查功能与有效租约 |
| F09 | 运营统计????? | 应用/卡种/时间维度的签发、激活、到期、在线统计；明确每项口径 | UTC 日报，默认 30 天、最多 366 天，每 60 秒刷新；首次激活按授权去重，在线依实际有效租约，到期按当前排期统计 |
| F10 | 异常使用检测????? | 频繁激活、异常换绑和地区变化触发可解释记录；人工复核 | 默认 10 分钟激活 10 次、1 小时释放 3 次、24 小时可信国家变化；按窗口去重，只记录并人工复核；国家信息只接收受信直接代理 |
| F11 | 通知与提醒????? | 到期、异常、批量结果等事件可配置接收人和渠道；失败重试和去重 | 站内通知与签名 Webhook；接收人独立未读状态，3/7/30 天到期提醒；持久事件去重，Webhook 最多 5 次自动尝试、24 小时过期 |
| F12 | 管理员双重验证（已完成） | TOTP 设置与登录、一次性恢复码、敏感操作再次验证、防重放和加密保存 | 各角色自行启用；登录 challenge 与敏感操作证明各有效 5 分钟；无永久可信设备 |
| F13 | 精细权限????? | 操作与应用范围分别授权，服务端强制校验；越权资源不可读取 | 标准用户—角色—权限模型、多角色权限并集与默认拒绝；应用/渠道范围独立取交集，变更即时撤权，提交前重查；保留至少一个启用的内置管理员 |
| F14 | 备份与恢复????? | 定期备份、保留与失败状态；在隔离环境完成恢复验证 | 配置后手动或每日备份，默认保留 7 份；数据库及必要密钥整体认证加密；恢复只创建隔离数据库，目标 RPO 24 小时，RTO 记录实际耗时 |
| F15 | 服务监控????? | 验证接口可用性、延迟、错误率、数据库状态；告警可追踪 | 内置状态页和 Prometheus 指标，每 60 秒采样；数据库失败立即告警，足量样本下 5xx≥5% 或 p95≥500ms 连续 3 次告警；采样保留 30 天、事故 180 天 |
| F16 | 客户与订单????? | 客户、订单、卡密、设备关联；可追踪续费售后 | 客户属于单一应用及可选渠道，可停用或匿名化；订单保存价格/授权快照，人工履约事务幂等；交付密文默认保留 30 天，普通查询不返回明文 |
| F17 | 代理与渠道????? | 独立额度、售价、应用范围、渠道数据权限 | 单级渠道、整数发卡额度、整数分报价；每张发卡或续期消耗 1，失败回滚，调整写入不可变流水；渠道业务必须通过订单履约 |
| F18 | 支付自动发卡（暂缓） | 验证支付回调、重复回调不重复发卡；交付状态与退款联动 | 用户于 2026-10-08 明确“暂时不做支付”；本轮订单采用人工履约 |
| F19 | 客户自助页面????? | 验证用户身份后查看授权、续费和申请换绑；不可凭可猜标识越权 | 256 位随机访问码换取独立 8 小时 Bearer 会话；轮换/停用即撤销；续期和换绑由后台审批，换绑仍受次数与冷却限制 |
| F20 | 开放 API/Webhook????? | 应用级凭证、权限、限流、签名通知、重试和去重 | 凭证只授予指定业务权限，每凭证 60 次/分钟，轮换即时失效；订单请求 ID 幂等；Webhook 使用 HMAC 签名、至少一次投递且无顺序保证，接收方按事件 ID 去重 |
| F21 | 客户端版本控制????? | 配置最低支持版本、升级提示与停用策略，兼容现有客户端 | 严格三段 0–9999 版本且无前导零；默认兼容旧客户端，强制策略在激活/心跳返回 426；仅发布升级信息，不自动安装更新 |
| F22 | 离线授权????? | 签名许可证包含产品、功能、期限与设备范围；客户端离线验签 | ES256/JWS，公钥由独立可信渠道配置；默认 24 小时、最多 168 小时且不超过卡密期限；逐次检查期限/设备/功能并持久化可信时间，撤销延迟最长为剩余离线期限 |

## 建议交付顺序

1. 账号与售后：F01、F04、F12，已于 2026-10-06 完成。
2. 授权策略：F02、F05、F06、F07、F08，已于 2026-10-07 完成。
3. 运营与可靠性：F03、F09、F10、F11、F13、F14、F15。
4. 商业集成：F16、F17、F18、F19、F20。
5. 客户端能力：F21、F22。

2026-10-08 用户确认按以上顺序实现剩余功能，并明确暂缓支付。新增规则见 [运营与可靠性](2026-10-08-operations-reliability-design.md)、[客户/渠道/自助/开放接口](2026-10-08-commerce-integrations-design.md)、[客户端版本与离线授权](2026-10-08-client-extensions-design.md)，执行计划见 [本轮计划](../plans/2026-10-08-roadmap-completion.md)。功能只有在对应实现和验证完成后才会标记完成。
