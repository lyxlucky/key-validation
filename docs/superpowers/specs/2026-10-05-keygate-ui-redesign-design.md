# KeyGate 全站 UI 重绘设计

日期：2026-10-05
状态：用户已确认，实施与验证完成。最终生产构建通过，11 项浏览器测试通过。

## 目标与选择

将现有 C# + React 卡密管理后台统一重绘为浅色专业工作台。用户已从浅色工作台、深色控制台、温暖简约风中选择第一种：深石墨导航、雾白内容区、蓝色主操作、信息清晰紧凑。浅色工作台适合长时间阅读列表；深色方向更突出技术氛围，温暖方向更柔和，本次采用用户选择。

统一视觉规则见 `design-system/MASTER.md`。本次覆盖五个页面与其所有对话框、抽屉、加载、错误和空状态。

## 页面结构

### 登录

桌面使用深石墨品牌区与白色登录表单的双栏布局。品牌区展示 KeyGate、授权管理价值说明，以及用线条和图标绘制的“卡密 → 设备 → 验证”流程示意，不展示虚构运营数据。表单区保留用户名、密码、错误消息、登录按钮与联系管理员说明。手机压缩品牌区，优先展示登录表单。

### 工作台与概览

桌面侧栏宽 232px，顶部白色栏高 72px。侧栏四个入口保留“概览 / 应用管理 / 卡密管理 / 操作审计”，当前项蓝色高亮。顶栏显示当前位置和用户信息。

概览页顺序为：

1. 页眉：工作台分类、概览标题、用途描述、生成卡密主按钮。
2. 四张等宽指标卡：卡密总量、已激活卡密、有效授权、在线会话；显示已有服务端数据及指标口径。
3. 主区域：最近生成的卡密列表，占主要宽度；右侧为简洁的授权管理流程与应用管理入口。
4. 页脚：产品名与设备时区说明。

不增加没有接口依据的收入、趋势图或健康状态。右侧流程在窄屏改为下方区域，保留可用入口。

### 应用管理

页眉突出创建应用按钮。内容面板具有“应用列表”标题、总数与简洁用途说明。表格中应用名称结合蓝色图标，应用标识使用等宽字体，状态标签统一，管理卡种与启用/禁用操作保持清晰。空状态说明从创建应用开始。

创建应用弹窗采用图标标题、名称与唯一标识表单、底部取消/创建按钮。卡种抽屉顶部显示所属应用摘要，下方为卡种表格与创建按钮。卡种编辑表单桌面两列排列时长和设备数，手机改为单列。保留“修改卡种只影响之后生成的卡密”等规则说明。

### 卡密管理

页眉保留生成卡密主按钮。列表面板按“标题与总量 → 筛选工具栏 → 完整卡密精确查找 → 表格 → 分页”组织。应用、状态、批次筛选分组清楚，支持重置筛选；刷新独立命名。完整卡密查找有可访问标签，并保持查询后清空明文输入。

表格突出脱敏卡密标识与状态，其次是应用、时长、设备上限和时间，详情列固定在右侧。详情抽屉顶部展示卡密摘要及禁用/恢复按钮；其下为授权信息、设备绑定、会话三个清楚分组，移动端信息表单列显示。

生成卡密弹窗视觉上区分“配置发行 → 保存结果”。保留当前应用/卡种/数量/备注字段和验证逻辑；结果区清楚显示一次性导出入口及关闭后无法再次查看的提示。响应丢失时采用醒目的恢复面板，保留原始批次请求标识和禁用原批次后重新签发的业务逻辑。

### 操作审计

顶部展示审计用途，下方统一列表面板。操作类型、操作人、对象、日期范围组织为能换行的筛选工具栏。操作类型用简洁图标或标签区分，时间稳定排列，长 ID 使用等宽截断与完整内容提示。表格总数来自接口，不添加推断统计。

## 组件、数据流与实现边界

- 在 `main.tsx` 使用集中式 Ant Design theme token，CSS 自定义属性统一背景、文字、边线和间距。
- `App.tsx` 管理桌面/平板/移动导航；共享品牌和页眉组件统一站点身份。
- `components/common.tsx` 负责页眉、状态、错误和空状态等复用表现。
- 各 feature 页面负责其页面结构；原有查询、表单提交和权限继续留在各 feature 中。
- 重绘登录、概览、应用、卡密、审计、卡种抽屉、卡密详情抽屉、发行弹窗。
- 不增加后端接口依赖，不改变授权时长、设备绑定、心跳或幂等语义。
- 空/加载/失败状态覆盖所有数据面板；失败入口提供重试，提交按钮保留 loading 与重复提交保护。
