# 开发接入助手 MCP 设计

日期：2026-10-11。状态：实现与独立审查完成；后端 402 项、专项前端及本机 MCP 验证通过。生产 Docker/Nginx/HTTPS 未实测，详见 docs/verification.md。

## 目标与成功标准

为第三方开发者的 AI 编程助手提供接口文档、C# / Python / JavaScript 示例和联调指引。开发者从系统集成页面复制远程 MCP 配置，连接后即可查询正确接口并编写激活、心跳和授权检查代码。首版提供公开开发资料，不查询真实应用、客户、卡密或订单，也不代开发者执行激活或其他业务操作。

## 架构与部署

使用官方 MCP C# SDK 的 ASP.NET Core 集成，在现有 API 进程内提供匿名、无状态的 Streamable HTTP `/mcp` 端点。不新增服务或数据库表。SDK 版本在实现前核对官方文档和当前 .NET 10 兼容性后锁定；初始化、协议版本协商、发现和调用均交由 SDK 实现。

增加 Nginx `/mcp` 专用代理规则，保留 HTTP 请求及协议头，禁用响应缓冲；本地 Vite 增加对应代理。页面默认以当前站点 origin 拼接 `/mcp`，本地开发和生产均通过同源代理访问。API 直连时使用 API origin。生产端点遵守现有 HTTPS 要求，使用可信代理解析后的客户端地址限流。允许无 Origin 的编程客户端；存在 Origin 时校验配置的站点白名单，并使用 SDK 支持的主机校验以防 DNS rebinding。

## 共享开发资料

后端建立不依赖数据库的 DeveloperDocumentationCatalog，维护版本化公开资料。每份资料有稳定 ID、标题、主题、正文及相关接口；接口记录包括操作 ID、HTTP 方法、完整路径、认证方式、请求与响应说明、错误码。

提供匿名只读 `/api/integrations/developer-docs` 索引和 `/api/integrations/developer-docs/{id}` 内容端点，现有接入说明页与 MCP 从同一目录读取资料。目录只包含显式维护的开发内容，不打包整个仓库、不公开后台完整 OpenAPI、配置文件或运维文档。现有 HTTP 契约和实际端点是校对依据；自动化测试核对目录中的方法和路径确实存在。

主题覆盖：快速开始、卡密激活、试用、心跳与功能门禁、退出、设备解绑、版本检查、离线验证及常见错误。离线资料说明 ES256、本地可信公钥配置和撤销延迟，并引用现有 C# 示例；首版三种语言的可运行模板覆盖在线授权流程，不宣称均提供完整离线验证实现。

## MCP 能力

同时提供 resources 和 tools，使客户端可通过资源读取或工具调用获取资料。资源 URI 为 `keygate://docs/{id}`，返回中文 Markdown，不包含实际业务数据。

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| `search_integration_docs` | query：1–200 字符；limit：1–10，默认 5 | 匹配条目的 ID、标题、摘要和资源 URI |
| `get_integration_doc` | docId：目录内稳定 ID | 完整文档和资料版本 |
| `get_api_reference` | operationId：目录内操作 ID | HTTP 路径、字段、认证、响应及错误处理 |
| `get_code_example` | language：csharp/python/javascript；scenario：online-license | 经过验证的固定模板、运行要求、使用说明 |
| `get_troubleshooting_guide` | errorCode：1–100 字符；operationId：可选 | 已知原因、排查步骤及重试或停止规则 |

工具均标记为只读。示例返回固定、受版本控制的源码模板，API 地址、应用标识和卡密由开发者在本机通过环境变量或运行参数配置。服务不接收卡密、令牌、任意 URL、源代码或原始日志，也不抓取第三方地址。未知文档或操作、无效枚举返回明确工具错误；搜索无匹配返回空结果；未知错误码返回通用排查指引并说明未收录，不推断服务器事实。

首版不依赖 prompts 能力；页面提供可复制的自然语言提问示例。

## 示例行为要求

三种在线模板均包含激活、心跳、有效授权与功能检查，以及退出清理；稳定设备标识在本机保存，会话令牌仅驻留内存。请求字段及响应以实际契约为准。根据服务端 heartbeatIntervalSeconds 调度；有效期同时受授权、租约和会话绝对期限约束，使用单调计时避免本机时钟调整延长租约。

明确拒绝时停止受保护操作；网络故障、429 和暂时不可用可在上一有效租约内进行有界重试，读取 Retry-After，租约到期即停止。每次受保护操作重新检查当前租约与所需 features。示例不记录卡密或令牌，不把商家 API 凭证嵌入客户端，不用退出进程代替业务门禁。JavaScript 模板面向 Node.js，明确运行版本和所需依赖；Python、C# 同样提供准确的启动说明。

## 系统集成界面

在现有接入说明、API 凭证、Webhook 旁增加“MCP 接入”页签，沿用页面现有可访问权限。展示远程地址、免凭证与公开资料说明、功能列表、复制配置和示例提问。连接配置仅针对实现时核实支持的客户端生成，注明对应客户端及配置位置，避免使用一个 JSON 假定兼容所有工具。客户端支持情况以官方资料为依据，不承诺未验证的客户端。

接入说明页改为读取共享目录，保留易读的分节与复制功能；加载失败显示错误与重试。MCP 页不创建凭证、不查询真实应用列表，示例使用占位应用标识。

## 请求控制与异常

`/mcp` 和公开开发资料端点使用独立的每 IP 每分钟 60 次默认限额，可配置，同时受现有全局限流约束；返回 429 与 Retry-After。请求体上限 64 KiB，且对无 Content-Length 请求同样有效。搜索与工具参数设长度和枚举限制，返回内容仅来自静态目录，避免无限输出。

HTTP 级异常保留正确状态码；MCP 调用错误使用 SDK 协议错误，不由现有异常处理中间件改写成成功响应或无关 HTML。MCP 不受 admin CSRF 和商家 Bearer 鉴权约束；已有后台访问控制继续执行，不新增全局放行规则。

## 验证与验收

1. 使用官方 MCP 客户端完成 initialize、tools/list、tools/call、resources/list 和 resources/read，验证匿名端点返回协议响应。
2. 验证未知参数、无匹配、未知错误码、限流、体积限制、Origin 拒绝，以及不会访问业务服务或外部 URL。
3. 文档目录路径、认证说明和关键字段与实际客户端端点一致；页面和 MCP 返回同一资料版本。
4. 三种示例验证正常激活、调度心跳、功能缺失、明确拒绝、暂时网络失败及租约到期停止。通过受控假服务验证时间与重试行为，避免消耗真实卡密。
5. 前端构建及页面验证通过，复制出的配置可解析，地址在本地代理与生产 Nginx 下可路由到 API。
6. 运行相关后端单元与集成测试，检查匿名 MCP 不改变既有后台权限和客户端接口行为。
