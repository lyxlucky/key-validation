# 客户端版本与离线授权规格

日期：2026-10-08。范围：F21、F22。保留所有默认在线客户端行为。

## F21 客户端版本

应用策略：minimumVersion、latestVersion、enforceMinimum、updateUrl、releaseNotes、sha256。版本严格为0–9999的 `major.minor.patch`，各段除0本身外不得有前导零，不接受前缀或预发行字符串；设置minimum时必须设置latest且latest不得小于minimum，强制策略必须有minimum。默认无最低限制，兼容缺少版本字段的旧客户端。

激活/试用正文新增可选 clientVersion，会话记录版本。心跳可通过 `X-Client-Version` 更新，缺失时使用激活版本。启用强制限制后，缺失版本返回 CLIENT_VERSION_REQUIRED，低于最低返回 CLIENT_UPGRADE_REQUIRED（426）；每次激活/心跳重新读取当前策略。合法版本低于latest时返回升级提示，不延長租约。

拥有`platform.manage`者配置策略；管理查询允许`platform.manage`或`licenses.read`且仍校验应用范围。公开版本查询仅返回版本及更新信息，不返回配置秘密。更新地址限HTTPS（Development/Testing环境且显式启用loopback例外时允许本机HTTP），sha256必须为64位十六进制。服务只发布升级信息，不自动执行下载的软件；安装包由软件发布方签名，客户端在安装前验证发布方签名和给定摘要。

## F22 离线授权

使用 ECDSA P-256 / SHA-256、JWS紧凑格式，签名固定IEEE P1363，头 `{alg:"ES256",typ:"KG-OFFLINE",kid}`。配置当前kid和私钥，缺失时明确未配置，不自动生成生产秘密。支持保留旧公钥验证与切换新kid；公钥通过受信配置部署到客户端，不能信任许可证自带公钥。

载荷包含格式版本、唯一序列号、applicationCode、licenseId、bindingId、features、issuedAt/notBefore/expiresAt、deviceHash。deviceHash为SHA256(normalizedAppCode + "\n" + 原设备标识)，客户端可重算。管理端签发时须输入原设备标识并通过现有应用范围内SHA-256绑定摘要精确核对，服务不保存原文。

仅正式、已激活、未禁用/冻结/到期且应用启用的授权和未释放绑定可签发。有效期1–168小时，默认24小时，且不超过卡密期限。受授权管理权限及范围限制，敏感操作遵守MFA。签发记录独立保存；同绑定重新签发或后台撤销标记旧记录撤销，在线查询会拒绝已撤销记录。冻结/禁用/释放不会让已离线设备即时得知：最长延迟是该离线许可证剩余有效期，管理台明确显示这一事实。

客户端验证签名、算法/kid、格式版本、应用/设备、起止时间、功能。每次受保护操作检查有效期和权限，进程内单调计时；跨重启保存最近可信UTC时间并拒绝明显回拨（容差5分钟），保存失败不授予离线能力。无可信硬件/网络时间时无法保证抵抗整盘快照回退或本地程序篡改，文档准确说明。

示例通过 `KEYVALIDATION_OFFLINE_FILE` 与受信公钥配置选择离线模式，完全不发网络请求；支持必需功能检测与过期退出。在线示例新增版本发送和升级提示。私钥只在服务端，生成的公开材料不含私钥；备份涵盖签名密钥。

## 验收

真实接口测试验证默认旧客户端、版本比较/畸形/强制门禁、策略更新后心跳阻断、更新提示和租约；离线签发权限、绑定/期限/状态/撤销/轮换。客户端用真实ECDSA签名验证篡改、未知kid、错设备/应用、过期/尚未生效/回拨、功能与持久状态失败。浏览器配置版本、签发与下载许可证、查看撤销状态；秘密和许可证内容不进入测试trace。
