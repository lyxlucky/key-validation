# Windows客户端手动测试程序

用户已明确选择Windows桌面程序、通过按钮操作，并要求在全部spec实现、验证与审查通过之后制作。本文件细化总计划Task7；准备文档不启动C#实现，程序代码必须等待Task6通过。

## 交付形态

采用.NET10 WinForms，输出可直接运行的Windows程序，中文界面。复用现有`KeyValidation.Client`的在线协议、单调租约、功能检查及离线验签/可信时间组件，管理配置通过现有Web后台操作。WinForms在当前机器具备运行时，支持按钮自动化和单独发布，不引入额外WebView或桌面UI依赖。

用户启动后能填写或载入测试配置，执行一次完整在线或离线授权流程，观察状态，再通过后台修改授权以验证后续行为。默认API为`http://127.0.0.1:5080`；远程只允许HTTPS，拒绝URL凭据、查询串/片段和自动重定向。

## 界面与流程

共用区域提供API地址、应用标识、客户端版本、设备标识及设备名称。默认设备标识在本机生成并稳定保存；界面允许显式更换用于手动测试。应用/设备/服务地址更改、切换授权模式或清除会话时，取消旧请求并释放旧本地权限。当前授权中的配置应锁定或先结束当前授权，不能把原服务令牌发给新地址。

在线区域提供：卡密激活、领取试用、立即心跳、启停自动心跳、退出会话、释放当前设备、检查公开版本。卡密输入默认遮蔽；会话令牌不显示、不保存。状态展示授权ID、正式/试用、卡密期限、会话绝对期限、租约倒计时、已授予功能、版本最低/最新与升级说明。版本可留空以测试兼容客户端；填写时必须符合服务端严格三段版本规则。

自动心跳按服务端间隔执行，不重叠。网络失败、429或5xx不能延长本地租约，仍可在最后租约内使用；到期立即关闭受保护操作。明确的授权拒绝和426立即撤销本地权限并显示原因及版本提示。退出无论网络结果如何都停止本地权限；只在服务端确认后显示远程退出成功。设备释放的额度/冷却拒绝应显示真实原因，不能显示成功；模糊网络结果要说明未确认，避免保留可能已经释放的本地权限。

离线区域通过文件选择器分别载入`.kglicense`和来自独立可信渠道的公钥JSON，显示文件名及验证后的授权元数据，提供验证/清除按钮。进入离线模式后停止在线计时请求并取消在途请求；从载入到受保护操作均不建立网络连接。失败不回退在线。每次操作调用现有`OfflineLicenseSession.Demand`，持久时间存储不可用、回拨、错设备/应用/公钥、篡改或到期都拒绝。界面说明后台撤销的可知延迟最长为剩余离线期限。

提供两种真实受保护演示操作：仅需有效授权的基础操作，以及要求`export`功能的CSV导出。按钮状态只是提示，事件处理器执行前再次检查当前授权与功能；界面明确说明禁止原因。示例CSV只包含演示数据，通过用户选择的保存位置写入。

诊断区域保留有限条内存记录：时间、操作、HTTP方法/固定路径、状态码、耗时与安全错误代码。不会记录请求/响应正文、认证头、卡密、令牌、访问码、原始设备标识或完整许可证。允许手动清除和导出经过限制的诊断。帮助区链接本地接入文档和手动用例。

## 配置与状态

提供占位值的`demo-profile.example.json`和显式“载入测试配置”操作。真实本机测试资料由控制器在`.local`中准备，不进入示例源码、日志或截图；命令行可传配置文件路径，不能传卡密/令牌值。配置中的卡密只进入当前内存，不自动回写。公钥选择来自配置/文件的显式信任动作，不能使用许可证中携带的键。

只自动保存设备标识和必要的非秘密偏好；可信UTC状态使用现有独立`FileTrustedTimeStore`，不可提供绕过校验的自动重置。关闭程序停止计时器、取消请求和释放资源，迟到的激活/心跳响应不能恢复已清除的状态。错误在界面内可读地展示，避免未处理异常或阻塞性的重复消息框。

## 验证与手动用例

新增测试覆盖桌面协调层的真实行为边界：有/无功能、租约精确到期、暂时网络失败不续租、明确拒绝立即收权、退出/模式变化后迟到响应不可恢复、自动心跳不重叠，以及离线失败不产生网络请求。用可控时钟和受控HTTP响应验证时间/竞争；签名使用真实ECDSA或现有真实签名测试工具，不用伪签名替代。

实际WinForms按钮烟测必须通过真实本机API完成正式激活、心跳、公开版本、退出/设备释放，并展示一次明确拒绝；离线使用真实服务器签发文件和独立公钥完成验证与功能门禁。同时检查窗体至少在1024×768和1440×900大小能看到主要操作、键盘顺序与缩放布局合理，并保存不含秘密的预览。基础测试和真实API烟测分开记录，不重复累计。

README提供构建/运行/发布命令、可运行程序位置、配置文件格式、后台准备步骤，以及逐步用例：正式授权与试用升级、禁用/冻结后的心跳、版本门禁、并发/设备限制、释放与换绑冷却、暂停心跳后到期、功能差异、离线篡改/错设备/过期/回拨和撤销延迟。涉及后台配置的步骤给出具体菜单与预期结果。
