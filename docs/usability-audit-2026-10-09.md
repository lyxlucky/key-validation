# 界面与交互细节排查

日期：2026-10-09。

本次从用户指出的应用创建、应用标识复制、发卡应用搜索和结果衔接开始，扩展检查后台全部 22 个页面，以及客户门户、公共弹窗和表单组件。检查采用源码审查、真实本地 API 浏览器操作、模拟大量应用及失败响应、截图检查相结合的方法。

## 已确认并修复的问题

| 编号 | 场景与原问题 | 修改后的行为 | 确认方式 |
| --- | --- | --- | --- |
| U01 | 创建应用必须手工想一个符合规则且不重复的标识 | 打开创建窗口时自动生成 `app_` 加 32 位随机标识；只需填写名称，也保留自定义能力 | 源码、浏览器仅填名称提交 |
| U02 | 应用标识及部分业务 ID 没有复制入口 | 应用列表和设置、卡密 ID、批次 ID、签发人 ID、订单与请求 ID 提供明确的复制按钮、完整文本提示和失败反馈 | 源码、浏览器复制应用标识 |
| U03 | 应用列表只能翻页寻找应用 | 新增按名称或标识搜索，搜索包含所有页；无匹配时说明调整条件；搜索状态下刷新正确的目录数据 | 65 个模拟应用，搜索第 65 个应用 |
| U04 | 应用创建成功后缺少接续配置入口 | 创建窗口关闭动画结束后打开该应用设置，继续引用卡种；避免窗口同时出现 | 浏览器创建流程 |
| U05 | 创建应用失败只出现短暂消息，提交期间表单和退出入口不一致 | 错误留在表单内，保留填写内容；提交期间锁定输入、取消和关闭，防止重复提交 | 源码、相关提交回归 |

| U08 | 发卡配置与结果分别开关两个弹窗，动画和焦点没有连续衔接 | 使用同一个弹窗切换配置和结果；保持宽度，短淡入过渡；结果出现时重置内容滚动并聚焦生成结果标题 | 浏览器验证同一弹窗节点、焦点、动效与截图 |

| U10 | 发卡目录加载、失败或无数据容易被误认为无可用选项；无卡种说明容易造成找错入口 | 在弹窗内显示应用加载和失败重试；说明暂无可用应用；无可发行卡种时指向应用设置引用及全局卡种管理 | 源码、无卡种与失败状态测试 |
| U11 | 多个异步编辑弹窗取消按钮看起来可点，实际被忽略；部分关闭图标仍显示可用 | 创建、卡种、客户、渠道、订单、售后、凭证、试用、冻结、风控、账号等提交期间显示禁用取消；补齐关闭和表单锁定 | 源码、发卡延迟提交、订单与表单生命周期回归 |
| U12 | 点击编辑弹窗外部可能直接丢弃输入 | 对主要异步编辑弹窗关闭遮罩点击退出，保留明确的取消/关闭入口 | 源码、既有编辑流程回归 |
| U13 | 批次详情/风险复核跳到卡密时旧浮层留在工作区中 | 跳转前关闭来源浮层；风险复核提交期间禁止跳转 | 源码、批次关联及工作区流程 |
| U14 | 客户、订单、渠道与门户详情请求较慢时显示空白抽屉 | 显示抽屉加载状态，然后呈现真实详情；保持失败重试入口 | 源码、订单交付和门户业务回归 |
| U15 | API 凭证/Webhook 创建后秘密窗口与编辑窗口衔接不顺；部分一次性内容只能手选保存 | 编辑窗口结束关闭动画后显示秘密；通用秘密支持下载，恢复码支持下载/复制全部，认证器手动密钥支持复制；交付复制复用统一失败反馈 | Webhook 创建、API 凭证权限、秘密清理、安全设置回归 |

修改保留发卡的原请求恢复协议。网络响应不确定时仍使用同一请求 ID 重试，不因体验调整重新生成请求或重复发卡。一次性卡密和秘密仍不写入浏览器持久存储，关闭后从 DOM 清除。

## 仍需单独安排的改进

这些项目已识别，未在本次实现，避免把检查结果误写为已完成：

1. **统一草稿退出保护**：目前主要编辑器可防止误点遮罩，但显式取消、关闭工作区标签仍会丢弃未提交草稿。发卡结果关闭与刷新已有提醒，关闭整个工作区标签的统一保护尚未覆盖。
2. **大目录服务端搜索**：应用列表跨页搜索与发卡选项使用现有可见应用目录。数千/数万应用时，应增加服务端搜索和分页选择，减少目录读取成本。本次大量选项验证使用 65 个模拟应用，真实环境有数百个测试应用。
3. **表格个性化与移动端操作入口**：宽表格保留内部横向滚动。列显示/密度设置、更多固定操作入口及移动端摘要视图仍是后续优化项。
4. **首次加载体积**：生产构建仍提示主 JavaScript 包超过当前体积阈值。路由按需加载及图表/集成说明分包应作为独立性能工作验证。

本次没有对 Windows 桌面示例进行 GUI 全流程验收，也没有穷举备份恢复、权限组合及每项业务配置的全部异常分支。相关后端业务规则和数据库结构未修改。

## 验证记录

生产构建：`npm run build` 通过；仍有上述包体积提示。

最终验证分批执行，避免真实登录触发每分钟 10 次的服务端限流：

- 核心体验与编辑器生命周期：30 项连续两轮，60 次执行全部通过。
- 后补的卡种/应用设置间距：375/768/1440px 三项通过；正常/减少动画发卡两项再验证通过。
- 全部后台页面：三项通过，每项遍历 22 页，共 66 个页面/宽度组合，包含实际筛选控件到表格的间距检查。
- 共享卡种业务：8 项全部通过。
- API 凭证权限、额度丢失响应恢复、密码/双重验证恢复、设备策略、订单恢复、订单权限隔离及客户门户流程分别回归通过。

Webhook 真实本地 API 创建复测未通过：服务端以 `WEBHOOK_TARGET_BLOCKED` 拒绝测试地址，页面保留表单并展示正确错误。这属于本地出站配置限制，不能记为真实创建/轮换通过；新增模拟成功响应检查已验证编辑窗口关闭后展示唯一密钥窗口及关闭后的明文清理。
