# KeyGate UI 设计系统

更新：2026-10-09

## 方向

浅色专业工作台。用于软件授权日常运营：签发卡密、配置应用和卡种、查询设备与会话、追踪管理操作。

依据 UI/UX Pro Max 的 Data-Dense Dashboard 建议，采用清晰表格、紧凑工具栏、分组表单与中性色层次。舍弃自动推荐中不适用于后台的营销页结构、玻璃拟态和外部字体依赖。

- 中文字体：系统字体、Segoe UI、Microsoft YaHei；数字与标识使用等宽字体。字体无需网络下载。
- 页面标题 28–30px / 650，区块标题 16px / 600，正文与表格 14px，辅助信息 12–13px。
- 采用 4px 间距刻度；桌面页边距 32px，移动端 16px；主要区块间距 24px。
- 面板圆角 12px、输入与按钮圆角 8px；边线为主，阴影轻量。
- 图标统一使用 Ant Design outlined 图标；不使用 emoji 作为图标。
- 状态同时有文字与颜色；避免无数据依据的趋势百分比、在线服务标记和图表。

## 工作台骨架

- 桌面：232px 深色侧栏 + 72px 白色顶栏 + 雾白内容区。
- 侧栏：KeyGate 品牌、工作空间名称、四个主导航、底部产品说明；当前导航用蓝色填充和白色文字。
- 顶栏：当前位置、移动端菜单按钮、当前用户、角色、退出入口。
- 平板 768–1023px：76px 图标侧栏，图标有可访问名称与 Tooltip。
- 手机 <768px：移除常驻侧栏，菜单按钮打开侧滑导航；点击目标后关闭，Escape 可退出。
- 主内容宽度最多 1600px；页面只纵向滚动，宽表格在自身区域横向滚动。
- 顶栏下依次为工作区标签栏、页面标题和主操作、页面内容、轻量页脚。

## 通用组件

- PageTitle：页眉分类、中文标题、用途描述、最多一个主要操作。
- Panel：区块标题、辅助说明、右侧操作、表格或表单主体。
- Metric：图标、指标名、大号数值、口径说明；加载显示骨架，失败显示明确重试。
- Status：圆点或图标 + 中文状态文本，低饱和背景。
- 表格：浅灰表头、48–56px 行高、行悬停、等宽标识、清晰操作列。
- 筛选：带标签的控件、完整卡密查找独立区域、重置与刷新明确命名。
- 抽屉：信息摘要、逻辑分组、响应式尺寸；多列表格保留内部横向滚动。
- 弹窗：图标与标题、简短用途说明、表单分组、稳定的取消/提交页脚。
- 危险确认：明确影响、操作对象和确认按钮；保留现有业务提示。

## 工作区页签与动效

- 左侧导航采用手风琴分组：展开一个时收起其他组；路由、历史记录和页签切换展开目的页所属组。
- 顶部采用 RuoYi 式独立标签：44px 白色标签栏，30px 高、3px 圆角的细边框标签，间距 6px，宽度随标题自适应。当前页签用主题蓝底、白色文字和小圆点标记；圆点预留位置，切换时标签宽度稳定。
- 标签支持切换、关闭和批量关闭；手机端标签栏高 56px，标签高 46px，切换与关闭操作的触控高度至少 44px。
- 页签溢出时保留鼠标可拖动的细滚动条；自动定位整个当前页签，包含关闭按钮。键盘方向键、Home/End、Delete 继续可用。
- 页面切换直接呈现保留的内容，隐藏页立即停用；不叠加进出动画，不用透明页面掩盖加载。筛选、草稿、查询参数与滚动位置继续保留。
- 侧栏宽度一次提交，避免在每个动画帧重新排列内容表格；颜色与透明度反馈控制在 150–180ms。
- 登录和退出使用一次整体淡入淡出；原生 View Transitions 与 CSS 回退动画不重复执行。尊重减少动态效果设置。

## 账号安全页

- 顶部显示登录保护状态和当前账号，下方按登录密码、双重验证、恢复码排列设置；状态与操作分开，主操作明确。
- 桌面以设置列表为主，旁边解释登录流程；窄屏按顺序单列排列，表单与操作按钮保持可触达。
- 不使用安全评分、短时验证倒计时或反复验证入口。双重验证跟随已认证登录会话；会话结束后重新登录。
- 开启认证器分为确认密码和扫码验证两步；关闭双重验证及重新生成恢复码只确认当前密码。绑定密钥和恢复码关闭弹窗后立即从 DOM 清除。

## 可访问性与响应式

- 普通文字对比度至少 4.5:1；可见键盘焦点，输入关联 label。
- 图标按钮有中文可访问名称；移动端主要触摸目标至少 44px。
- 提供跳到主内容入口；主内容为 main，侧栏为有名称的导航。
- 模态框管理焦点；保留 Ant Design 的 Escape 和焦点恢复。
- 尊重 prefers-reduced-motion，动画仅用于颜色、透明度和短距离过渡。
- 在 375、768、1024、1440px 验证每个页面；375px 下表单单列，指标两列，导航侧滑。

## 数据与安全约束

- 保留服务端角色、应用范围、会话时限、CSRF 和查询失效逻辑；双重验证证明绑定登录会话。
- 卡密明文只留在生成结果的临时状态；不持久化、不写日志。
- 不更改卡密签发幂等恢复、已提交但响应丢失处理、批次禁用后重新签发规则。
- 每个 Form 使用唯一 name；弹窗/抽屉关闭按钮可访问名称为“关闭”。
