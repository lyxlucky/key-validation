# 从零配置并使用 Windows 授权测试台

后台负责创建软件、授权规则和卡密；Windows 测试台模拟使用这些卡密的软件。先完成一次在线激活，再按需要测试试用、版本限制或离线授权。

本工作区的后台为 <http://127.0.0.1:5173>，API 为 `http://127.0.0.1:5080`。使用你的管理员账号登录后台。设备标识由桌面程序自动生成，第一次测试保留默认值即可。

## 1. 创建应用

打开「应用管理」→「创建应用」。例如填写：

| 字段 | 示例 |
| --- | --- |
| 应用名称 | 我的测试软件 |
| 应用标识 | `my-demo` |

点击「创建」。应用标识是桌面程序选择软件的依据，创建后不可修改。如果示例标识已经存在，使用一个新的标识，并在桌面端填写相同的值。

## 2. 创建卡种

在刚创建的应用右侧点击「管理卡种」→「创建卡种」。

| 字段 | 第一次测试建议 |
| --- | --- |
| 卡种名称 | 测试月卡 |
| 授权时长（小时） | `720`，即 30 天 |
| 设备上限 | `1` |
| 在线会话上限 | `1` |
| 激活期限（天） | 留空 |
| 授权功能 | 添加 `export` |

点击「保存卡种」。授权时长从首次激活开始计算；激活期限限制的是发卡后多久必须首次激活，留空表示不限制。

`export` 是测试台 CSV 导出操作要求的功能。基础操作只要求有效授权。授权时长、设备/在线上限、激活期限和功能在发卡时固定；修改卡种后，要生成新卡才能使用新规则。

## 3. 生成并保存卡密

打开「卡密管理」→「生成卡密」，选择刚才的应用与卡种，将「生成数量」设为 `1`，点击「确认生成」。

在「卡密已生成」窗口复制完整卡密，或者点击「下载 CSV」保存。完整卡密只在这次结果中提供；点击「已保存，关闭」后，服务端无法再次提供明文。列表中的卡密提示和授权 ID 都不能用来激活。

## 4. 在桌面程序中激活

启动程序，选择在线模式。程序位置和运行时要求见 [运行说明](../README.md)。

| 桌面字段 | 填写 |
| --- | --- |
| API 地址 | `http://127.0.0.1:5080` |
| 应用标识 | 第 1 步的标识，例如 `my-demo` |
| 客户端版本 | `2.1.0` |
| 设备标识 | 保留自动生成的值 |
| 设备名称 | 我的电脑 |
| 卡密 | 第 3 步复制的完整卡密 |

点击「卡密激活」。成功后，状态显示“在线有效”，并列出授权期限、功能和剩余租约。点击「执行基础操作」验证基础授权，点击「导出演示 CSV」选择保存位置并验证 `export` 功能。

保持「自动心跳」开启。默认约每 60 秒向服务端确认一次，租约约 180 秒；暂停心跳后，当前租约继续倒计时，到期便停止受保护操作。操作前会重新校验授权，按钮是否可点击只是状态提示。

API 地址使用 `5080`，管理网页使用 `5173`。如果配置项被锁定，先点击「退出会话」；仅需结束本地状态时也可点击「清除本地授权」。清除本地状态不会确认服务端会话已退出。

## 5. 验证后台管控

打开后台「卡密管理」，筛选刚创建的应用，进入这张卡的详情，可查看授权、设备绑定和会话。

| 要测试的行为 | 后台操作 | 桌面预期 |
| --- | --- | --- |
| 禁用 | 卡密详情 → 禁用卡密 | 点击「立即心跳」后明确拒绝，基础操作和导出停止 |
| 恢复 | 卡密详情 → 恢复卡密 | 重新激活后可用；有效期不会延长 |
| 冻结 | 卡密详情 → 冻结/解冻区域 | 冻结后心跳拒绝；解冻后重新激活，按规则恢复剩余时间 |
| 解绑 | 卡密详情 → 设备卡片 → 解绑设备 | 原会话失效，设备名额释放；有效期不变 |
| 功能差异 | 创建不含 `export` 的新卡种并发卡 | 激活后基础操作可用，CSV 导出不可用 |

桌面「退出会话」会结束本地权限，服务端确认后显示退出成功；它不释放设备名额。「释放当前设备」用于解绑，受到该卡的换绑次数和冷却策略限制。

## 6. 按需测试扩展功能

**试用升级：** 应用管理 → 管理卡种 →「试用授权」区域 →「配置试用」，开启「允许领取试用」并点击「保存试用规则」。桌面使用从未绑定正式授权的新设备标识，点击「领取试用」；之后在同一设备上输入正式卡密并点击「卡密激活」。同设备重复领取不延长试用，曾使用正式卡的设备不能重新领取。

**版本限制：** 打开后台独立的「客户端版本」页面，选择应用，设置最低版本 `2.1.0`、最新版本 `2.10.0`，开启强制最低版本并保存。桌面填写 `2.0.9` 时激活应被拒绝，并显示升级信息；填写 `2.1.0` 后可激活。版本每段必须是无前导零的 0–9999 整数。

**离线授权：** 先用正式卡在线激活，建立设备绑定；再到后台独立的「离线授权」页面点击「签发离线授权」。将卡密详情中的「卡密 ID」填入表单的「授权 ID」，再填写设备的「绑定 ID」、桌面使用的「原始设备标识」及「有效小时」，点击「确认签发」。保存生成的许可证，并在可信的管理后台点击「导出验签公钥」取得公钥 JSON；公钥要独立于许可证文件取得，不能信任许可证自行携带的键。桌面切换离线模式，分别选择 `.kglicense` 和可信公钥，点击验证。应用和设备标识须与签发时一致。离线期间不会发起网络请求，后台撤销的可知延迟最长为许可证剩余有效期。

需要检验设备上限、并发限制、换绑冷却、文件篡改、错设备、到期或回拨时，可继续阅读 [运行与测试说明](../README.md)中的客户端说明和手动用例。
