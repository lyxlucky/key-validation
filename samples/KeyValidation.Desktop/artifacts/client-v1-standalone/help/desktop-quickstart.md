# Windows 授权客户端使用说明

## 启动和登录

1. 确认本机授权服务正在运行（API 为 http://127.0.0.1:5080，后台为 http://127.0.0.1:5173）。
2. 打开 `samples/KeyValidation.Desktop/artifacts/client-v1-standalone/`，运行 `KeyValidation.Desktop.exe`。
3. 打开同目录的 `测试卡密.txt`，复制一张 30 天卡，粘贴到卡密输入框，点击「登录」。
4. 登录成功后显示「授权正常」、到期时间、最近验证、验证有效期、授权标识和设备信息。卡密输入框随即清空。

发布目录自带运行时，请完整保留目录内容。无需填写服务地址或应用标识；这两个参数已放在 `client-settings.json`。

## 在后台观察状态变化

后台「应用管理」中找到「KeyGate 授权客户端」，应用标识为 `keygate-desktop-client`。到「卡密管理」筛选该应用，也可按测试资料中的卡密搜索。客户端提供「复制授权标识」，方便核对详情。

- **禁用**：登录客户端后，在后台禁用该卡密。等待自动验证，或在客户端点击「立即验证」，会显示「卡密已禁用」并返回登录页。后台恢复后重新输入卡密登录。
- **冻结**：在卡密详情配置冻结，验证后客户端显示「卡密已冻结」并退出。后台解冻后重新登录。
- **续期**：在客户端保持有效登录时，后台给卡密续期。下一次成功验证后到期时间更新。已经到期时，先续期再重新登录。
- **到期**：使用资料中的 3 分钟卡，从第一次登录起等待 3 分钟。客户端会显示「卡密已到期」并退出。短时卡也可以在后台续期。
- **撤销会话**：在卡密详情的设备会话中撤销当前会话，下一次验证后显示「登录已失效」，返回登录页。
- **停用应用**：在应用管理停用该应用，下一次验证后客户端显示「应用已停用」。恢复应用后重新登录。
- **网络异常**：停掉授权服务或断开连接。客户端下一次请求失败时显示连接异常，租约不会延长；已有验证有效期结束后自动返回登录页。恢复连接后重新登录。

自动验证采用服务器返回的心跳间隔，目前为 60 秒。状态变化不等同于即时推送。「立即验证」只检查当前有效会话，不能绕过禁用、冻结或到期。

## 退出和安全保存

点击「退出登录」会立即结束本机授权并尝试退出服务端会话。关闭窗口也执行退出，最多等候 3 秒；网络异常时服务端会话按租约结束。

客户端不自动记住卡密或会话令牌。测试卡密文件属于本地测试资料，请自行保管。设备标识保持稳定，默认位于当前 Windows 用户的本地应用资料目录。

配置其他应用时，修改 `client-settings.json` 的应用标识、API 地址和版本后重启，再使用该应用的卡密。远程 API 必须采用 HTTPS。
